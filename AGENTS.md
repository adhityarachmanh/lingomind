# LingoMind

Aplikasi belajar bahasa. **Migrasi dari Dioxus ke Next.js SELESAI (Fase 6)** — aplikasi aktif = Next.js (main) di root; kode Dioxus legacy sudah dihapus (histori git tetap ada).

## Perintah

- Dev: `npm run dev` (http://localhost:3000)
- Verify: `npm run lint`, `npx tsc --noEmit`, `npm run build`, `npm test` (vitest — hanya lib murni)
- DB: `npm run db:generate` (generate Prisma Client), `npm run db:status` (migrate status), `npm run db:seed`, `npm run db:check` (cek koneksi + jumlah data), `npx prisma studio`

## Lingkungan (.env di root — jangan commit)

- `DATABASE_URL` — Neon PostgreSQL. Prisma 7 butuh driver adapter (`PrismaPg` di `lib/db.ts`); config Prisma ada di `prisma.config.ts` (bukan package.json). DB kosong saat setup — skema ditulis manual di `prisma/schema.prisma` (tidak ada `db:pull`); migration yang sudah applied: `20260731165924_init` + `20260731170113_align_fk_actions`
- `AUTH_SECRET` — jose JWT (cookie httpOnly `lingomind_session`, 30 hari)
- `SMTP_USERNAME`/`SMTP_PASSWORD` (Gmail app password) — tanpa password, email dicetak ke console server (mode dev)
- `APP_URL` (default `http://localhost:3000`)
- `OPENCODE_AI_API_KEY`/`OPENCODE_AI_ENDPOINT`/`OPENCODE_AI_MODEL` — AI provider opencode.ai (`ai` + `@ai-sdk/openai-compatible`); endpoint default `https://opencode.ai/zen/go/v1/chat/completions` (suffix `/chat/completions` di-strip di `lib/ai.ts`); model default `deepseek-v4-flash`
- `CRON_SECRET` — melindungi endpoint cron (Bearer `CRON_SECRET`); Vercel Cron otomatis kirim header `x-vercel-cron`

## Catatan lingkungan

- Node >= 22.12.0 (dibutuhkan `sanitize-html`)

## Konvensi

- UI & pesan error **bahasa Indonesia**; string error lama wajib dipertahankan (lihat `lib/actions/*`)
- Setiap server action yang butuh user memanggil `getSession()` — jangan pakai parameter email dari client
- Setiap server action admin memanggil `requireAdmin()` (di `lib/auth.ts`) → `"Akses ditolak."`; middleware melindungi `/admin` (session), role di-check layout admin (`app/(admin)/layout.tsx`)
- Dark mode: class `.dark` di `<html>`, key localStorage `lingomind_theme` (konsisten dengan aplikasi lama). Session localStorage lama TIDAK dipakai — user harus login ulang
- Aksesibilitas & polish: font Geist dipakai via `--font-geist-sans` (globals.css `body`), `:focus-visible` ring teal global, `prefers-reduced-motion` dihormati; security headers di `next.config.ts` (nosniff/SAMEORIGIN/Referrer-Policy/Permissions-Policy; CSP hanya production); `components/sessionGuard.ts` — `redirectIfSessionExpired(res.error)` dipanggil di tiap handler error server action user (redirect /login saat "Sesi berakhir")
- Anti-cheat skor: `submitQuizResultAction` & `submitExamResultAction` menolak `"Skor tidak valid."` bila `score !== correctCount * pts` / `correctCount` di luar jangkauan (hardening tingkat 1; anti-cheat penuh butuh tabel attempt — tercatat di AGENTS.md bawah)
- Admin seed: `admin@lingomind.com` (password `admin`) — **ganti password di produksi** (belum ada aksi ganti password admin di panel; gunakan Prisma Studio atau tambahkan nanti)
- Rate limit login: maks 5 gagal/15 menit per (email, IP) via model `login_attempts` (`lib/actions/auth.ts` — berlaku untuk user + admin)
- Jangan commit `.env`
- HTML AI (lesson content, soal quiz) WAJIB lewat `sanitizeHtml()` (`lib/sanitize.ts`) sebelum `dangerouslySetInnerHTML`
- Fungsi murni (SM-2 di `flashcards.ts`, streak/outcome di `progress.ts`, validasi quiz, classifier `weakness.ts`, parser `ai-content/parse.ts`) diuji dengan vitest (`*.test.ts` di `lib/`)
- TTS = Web Speech API (`components/SpeakButton.tsx`), bahasa dari `language.tts_lang_code` (fallback `en-US`)
- STT = SpeechRecognition browser (`components/useSpeechRecognition.ts`; `webkitSpeechRecognition` fallback — butuh Chrome/Edge; `supported` untuk pesan error)
- Chat (fase 3): sesi disimpan di DB (`chat_sessions`/`chat_messages` via `db.chatSession`/`db.chatMessage`); balasan AI memuat blok `Koreksi:` yang di-split `splitKoreksi()` di `lib/chat.ts`; goal `Bebas` → picker (tanpa auto-start). **Chat & voice-chat streaming**: `app/api/chat/route.ts` (`streamText` + `toTextStreamResponse`, persist di `onFinish`; user message disimpan sebelum stream, AI setelah selesai; history window 10 + pesan baru tanpa duplikat; `maxDuration 60`); `ChatView`/`VoiceChatView` membaca stream via fetch reader — `sendChatMessageAction` dihapus
- Quiz AI: cache 5 varian acak per (language, level, goal, modifier) di `cached_quizzes` (`contentJson`), dipick acak tanpa generate baru; **saat disajikan, `shuffleQuiz` mengacak urutan SOAL + opsi tiap soal (anti-hafalan posisi/urutan; pure, diuji di `lib/ai-content/quiz.test.ts`)** — dipakai `getQuizAction`/`getExamAction`/`getGeneralPracticeAction`/`getWeaknessPracticeAction`
- SFX benar/salah/menang (`components/playSfx.ts`): `new Audio("/{correct|wrong|winner}.mp3")`; error `NotAllowedError` (autoplay policy, mis. setelah `await`) → **di-antri dan dimainkan saat `pointerdown` berikutnya**; error lain → `console.warn`; `playSfx("winner"/"wrong")` di `finishQuiz`/`submitResult`/`finish` dibunyikan SEBELUM `await` (dalam jendela gesture)
- Konten siap = pre-generated (takeout): lesson/quiz/exam TIDAK lagi di-generate AI dari halaman user — cache-only (`getLessonAction`/`getQuizAction`/`getExamAction` return error "belum tersedia" jika kosong); `prefetchLessonAction` dihapus. **General practice = pool pre-gen 15 varian/level** (`CONTENT_GENERAL_PRACTICE_VARIANTS`): `getGeneralPracticeAction` pick acak dari pool (instan), fallback generate bila pool belum penuh — tema acak via `GENERAL_PRACTICE_THEMES` + `buildGeneralPracticePrompt(language, level, theme)`; soal menantang di ambang atas level. Weakness practice, chat, story, pronunciation, placement juga tetap AI on-demand
- Bulk pre-generation admin (panel "Konten" — **per-unit, bukan bulk**): tombol di kolom "Generate" tiap item status — `generateNextLessonAction` (bagian 1-3 berikutnya, modifier normal; "Semua bagian sudah digenerate" bila penuh; tombol Lesson disabled di panel saat 3/3) & `generateQuizVariantAction` (topik/exam/general_practice — maks `CONTENT_QUIZ_MAX_VARIANTS` = 10 varian per goal, anti-duplikat; **klik tombol Quiz → modal pilih jumlah (maks = sisa ke 10, action terima `count` dan generate N varian sekaligus)**; tombol Quiz disabled di panel saat 10/10; display varian aktual vs 10). **Cek duplikat existing**: tombol "Cek Duplikat" di panel → `checkQuizDuplicatesAction` (scan `cached_quizzes` bahasa terpilih via `detectQuizDuplicates` — pure, `lib/admin.ts` + test: flag varian yang punya ≥1 soal IDENTIK (normalisasi question+listen_text) atau MIRIP (Jaccard ≥ 0.7) dengan varian yang lebih dulu ada; keep-first, per grup level|goal) → laporan + tombol **Regenerate** per baris (`regenerateQuizVariantAction`: generate varian baru DULU via `generateOneContentUnit` [prompt diberi existingQuestions → anti-duplikat], **verifikasi via `isQuizVariantClean` (pure, `lib/admin.test.ts`) — masih identik/mirip dengan sisa grup → hapus hasil percobaan & retry maks 3×**; baru hapus row lama setelah ada pengganti bersih; gagal → row lama utuh; guard jangan hapus varian terakhir; setelah sukses auto re-check + pesan "cek ulang: X tersisa/bersih" — `refreshStatus` TIDAK menghapus message lagi). Target minimal per level = 1 varian per unit (`CONTENT_QUIZ_VARIANTS`/`CONTENT_EXAM_VARIANTS`/`CONTENT_GENERAL_PRACTICE_VARIANTS` = 1) + **3 lesson per goal** (`CONTENT_PARTS` = 3, `CONTENT_LESSON_MODIFIERS` = ["normal"]): `buildContentWorkList` + engine `resolveLanguageContentStatus`/`findNextUndoneUnits`/`findNextUndoneUnit`/`generateOneContentUnit` (pure/berbagi, `lib/admin.ts`). **Anti-duplikat isi dua lapis**: (1) prompt diberi contoh soal existing (`formatExistingQuestions` — maks 10 soal terbaru, termasuk `listen_text`, disuntikkan ke `buildQuizPrompt`/`buildGeneralPracticePrompt` lewat `existingQuestions`; pure, `lib/ai-content/quiz.test.ts`) + (2) retry otomatis 3× di `generateOneContentUnit` dengan `hasDuplicateQuiz` (≥1 pertanyaan identik — bandingkan question + listen_text agar soal listening tidak false-positive) & `hasDuplicateLesson` (judul sama / Jaccard konten ≥0.6) — pure, `lib/admin.test.ts`. **Generate massal via CLI**: `npm run content:generate <Bahasa>` (`scripts/generate-content.ts` — cli-progress, 3 unit paralel, resume idempotent, tunggu cooldown unit gagal otomatis). Unit yang gagal AI ≥3x di-skip SEMENTARA (`failed_content_units`, cooldown 30 mnt via `FAILED_SKIP_THRESHOLD`/`FAILED_COOLDOWN_MS`) — bahasa baru siap hanya jika SEMUA unit punya minimal 1 konten; reset via `resetFailedContentUnitsAction` (tombol panel); `parseAiJson` punya repair JSON terpotong; `getLessonAction` return `totalParts` (LessonView menampilkan "Mulai Quiz" di bagian terakhir)
- Gating bahasa: `getLanguages()` (`lib/dashboard.ts`, dibungkus React `cache()`) HANYA mengembalikan bahasa yang SIAP (semua level lengkap via `isLevelReady`/`isLanguageReady`/`computeLevelContentTargets` — pure, `lib/dashboard.test.ts`); `updatePreferredLanguageAction` menolak bahasa belum siap ("Bahasa belum tersedia.")
- Pipeline AI generic: `generateQuizWithPrompt` (quiz/practice/exam) di `lib/ai-content/quiz.ts` dengan retry otomatis (maks 2×) + **token budget otomatis** (`quizMaxTokens`: 3 soal → 4096, 5+ soal → 8192; override via `maxTokens`); lesson punya pipeline sendiri `generateLesson` di `lib/ai-content/lesson.ts`; placement inline di `lib/actions/placement.ts` via `generateText` (helper `buildPlacementPrompt`/`formatPlacementHistory`/`parseCefrLevel` di `lib/ai-content/placement.ts`) — prompt dikirim sebagai argumen; hasil dicek via `parseCefrLevel`, tanpa retry otomatis
- Latihan kelemahan: pool per topik (`goal="weakness"`, modifier=topik) maks `CONTENT_WEAKNESS_VARIANTS` = 3 varian (cukup cepat penuh → kunjungan berikutnya pick acak instan); `getWeaknessPracticeAction` generate on-demand hanya saat pool topik belum penuh; topik dari `getPriorityWeakness` (classifier `classifyWeaknessTopic`, list `WEAKNESS_TOPICS` di `lib/weakness.ts`) atau goal; **pre-gen massal via `npm run content:weakness <Bahasa>`** (`scripts/generate-weakness-pool.ts` — isi pool WEAKNESS_TOPICS + goal tiap level, idempotent, anti-duplikat retry 3×)
- Story & pronunciation cache: cerita interaktif di-cache di `cached_stories` (unique language|level|goal — `getStoryAction` cache-first via upsert; kunjungan kedua+ instan tanpa AI) & kalimat pronunciation di `cached_pronunciations` (unique language|level — `getSentencesAction` cache-first; evaluasi tetap on-demand). `getCurriculum()` dibungkus React `cache()` (dedupe per-request). - Kosakata bank (`/vocabulary`): kartu `kind="vocab"` di tabel `flashcards` (kolom `kind`, SM-2 sama dengan flashcard) — `VocabularyView` + `lib/actions/vocabulary.ts`; auto-populate dari `lesson.vocabulary` saat lesson dibuka (idempotent `skipDuplicates`, tanpa biaya AI); tambah manual/hapus/search; review khusus via `/flashcard-review?kind=vocab` (`getDueFlashcardsAction(limit, kind?)`); indikator dashboard via `getDueVocabularyCount`. Migration `add_flashcard_kind` belum di-apply
- Mastery per topik (`lib/mastery.ts`): `computeGoalMastery` (pure, test `lib/mastery.test.ts`) — level 0-5 dari lesson dibuka (`activityType="lesson"` di-log saat `getLessonAction` sukses, fire-and-forget) + quiz lulus; `nextReviewAt` = aktivitas terakhir + `MASTERY_INTERVALS` [1,3,7,14,30] hari; `reviewDue` saat jadwal lewat → badge 🔄 di roadmap (`RoadmapClient`) + prioritas tertinggi di kartu **Rekomendasi Hari Ini** dashboard (urutan: re-review mastery → kosakata due → kelemahan teratas → lanjutkan kurikulum)

- Ekstraksi kosakata dari chat (`lib/ai-content/vocab.ts`): di `app/api/chat/route.ts` `onFinish` — fire-and-forget `extractVocabularyFromChat` (maks 3 kata, `parseVocabList` pure + test) → `addFlashcards` `kind="vocab"` ke bank SRS user; tidak menahan stream; dipanggil hanya bila balasan ≥ 40 karakter
- CI: `.github/workflows/ci.yml` — push/PR → `npm ci` (env `DATABASE_URL` dummy agar prisma generate postinstall sukses) → lint → tsc → vitest. **Cicil konten otomatis**: `.github/workflows/content-generation.yml` — `on: schedule` tiap jam (`0 * * * *`) + `workflow_dispatch` (tombol manual), concurrency guard; `npm ci` → `prisma migrate deploy` → `npm run content:generate -- --all --max-units 6` → `npm run content:weakness -- --all --max-units 6`; secrets repo: `DATABASE_URL`, `OPENCODE_AI_API_KEY`, `OPENCODE_AI_ENDPOINT`, `OPENCODE_AI_MODEL`.
